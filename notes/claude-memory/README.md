# Project memory (Claude)

Standing decisions and lessons for this project, maintained by Claude
across working sessions at Tommy's request so collaborators can see them
in the commit history. Each file is one topic; the `pinned` frontmatter
flag marks notes that apply to every session.

These are the project's working agreements — read them before making
pipeline or visualization changes, and update them (in the same commit as
the change) when a decision here is revised.
